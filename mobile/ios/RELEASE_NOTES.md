# BruTV Release Notes

## Current source version: 1.0.1 (Build 16)

This is the current source version configured in the iOS project. Distribution status is pending verification.

BruTV plays live TV, movies, and series from user-provided Xtream Codes accounts or M3U playlists.

- Search channels and catalogs, browse categories, and save favorites.
- Switch channels from the player and use its in-player channel guide.
- View playback telemetry and select available audio and subtitle tracks.
- Enable the local live pause and rewind buffer in Settings.
- Import sign-in details with a QR code or `brutv://login` link.
- Use Picture in Picture where the platform supports it.
